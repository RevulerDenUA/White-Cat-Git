# White Cat UI

- Build the interface of a polished space game. Follow the existing 3D models, materials and visual style.
- Avoid recognisable AI patterns in composition, decoration and copy without sacrificing quality.
- Use one palette, typography system and set of component states across screens.
- Keep copy natural, short and appropriate to the action.
- Use verified NASA data where relevant. Label simulations and artistic scale; never invent scientific readings for decoration.
- Inspect the running game and screenshots at different resolutions; code inspection alone is insufficient.
- Ask the user about unclear mechanics, transitions or behaviour before implementing them.
- Current UI scope is the main menu and settings, including key rebinding. Coordinate other screens through documented interfaces.
