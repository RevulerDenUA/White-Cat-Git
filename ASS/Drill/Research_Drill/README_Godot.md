# Research Drill — файли для команди Godot

Актуальна версія після ручного видалення користувачем двох кріплень бічних дротів. Зміна перенесена в LOD1; усі GLB повторно імпортовано й перевірено.

- `Research_Drill.glb` — 3576 трикутників.
- `Research_Drill_LOD1.glb` — 2620 трикутників.
- `Research_Drill_LOD2.glb` — 1424 трикутників.

Кожен GLB самодостатній: один матеріал, дві вбудовані PNG 512×512. Окремо копіювати текстури не потрібно. Кожен файл містить повну установку; використовувати один LOD за раз. Автоматичне перемикання LOD у файлах не задане.

Метри, glTF +Y вгору. Габарит у нейтральній позі приблизно 0,66 × 1,321 × 0,80 м (X/Y/Z glTF).

## Рухомі вузли

- Корінь: `ResearchDrill` — площина ґрунту, вісь свердління.
- `Carriage/Auger_Rotating` — обертання навколо власної локальної +Y; локальну позицію зберігати. Нейтральний pivot відносно Carriage: `(0, -0.10, 0.215)`.
- `Carriage` — подача по +Y: зміщення від нейтральної позиції від −0,22 до +0,10 м. Нейтральна позиція `(0, 0.85, -0.215)`.
- `Leg_FL`, `Leg_FR`, `Leg_RL`, `Leg_RR` — хід по локальній +Y ±0,10 м від нейтрального положення. Їхні дочірні `Foot_*` обертаються навколо кульового шарніра, межа нахилу 20°.
- Сітки й трансформації вузлів узгоджені між LOD. Нейтральні трансформації вже збережені у файлах.

Це модель із підготовленими рухомими вузлами. Колізії, керування бурінням, пристосування опор до рельєфу та перемикання LOD належать логіці гри; Godot-скриптів і готових animation clips у цьому ZIP немає.

Редагований Research_Drill.blend та повна документація лежать окремо у повному пакеті Research_Drill_Package.zip.
