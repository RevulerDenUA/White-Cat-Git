# White-Cat-Git
Alternartive look at space exploration

The Godot 4.7.2 .NET project starts in `Scene/UI/MainMenu.tscn`. Main menu and settings integration, controls, station preview and verification commands: [UI integration](docs/ui/INTEGRATION.md). The main menu uses the existing White Cat station and opens `Scene/A.tscn` through a 3D camera transition.
